## 原型中原先缺失的后端支持

| 功能点 | 新增接口 | 实现说明 |
|---|---|---|
| 用例表格导入预检 | `POST /api/cases/import/preview` | 支持 CSV、JSON、XLSX；逐行返回规范化数据和错误，不在预检阶段写库 |
| 用例导入提交 | `POST /api/cases/import/commit` | 一次事务写入用例资产和首个不可变版本，最多 2000 条 |
| 用例导入模板 | `GET /api/cases/import/template` | 动态生成 XLSX 中文模板和示例行 |
| 调度时间预览 | `POST /api/scheduled-tasks/preview` | 将表单或 Cron 转为后续触发时间，明确使用 `Asia/Shanghai` |
| 可引用凭据目录 | `GET /api/secrets` | 只返回名称与作用域，不返回明文或密文；前端写入凭据引用占位符 |
| 质量门禁规则级管理 | `GET/POST/PUT/DELETE /api/quality-gate/rules` | 提供规则启停、阈值和名称管理；停用规则在评估器中真正跳过 |
| 最近真实响应采样 | `GET /api/endpoints/:id/last-response` | 从最近测试结果读取状态码、正文、耗时与采集时间，供断言编辑器使用 |
| 缺陷统一前端契约 | `defectsApi` | 对现有缺陷后端接口补齐统一前端调用封装 |

## 全局交互改造

- 导航改为原型中的七组信息架构，执行记录、质量门禁、数据库连接回到明确的业务分组。
- 顶栏增加面包屑、`Ctrl/Cmd + K` 全局功能搜索、通知入口和头像菜单。
- 侧栏固定为 224px，可折叠为 64px；移动端使用遮罩抽屉，避免内容区被压缩。
- 项目工作区直接展示项目内数据，质量分区不再只是四张跳转卡片。
- 用例导入采用“文件选择 → 预检 → 只提交有效行”的可审计流程。
- 断言编辑使用结构化规则，并可读取最近真实响应作为配置依据。
- 定时任务显示未来 5 次触发时间，避免只靠 Cron 字符串判断。

## 契约边界

- 运行结果模型当前没有持久化响应头，所以最近响应接口的 `headers` 暂返回空对象；状态码、正文、耗时和时间均来自真实执行记录。若后续要支持响应头断言取样，需要为 `test_results` 增加响应头字段及迁移。
- 凭据目录复用环境、仓库和数据库连接中的加密配置，只提供引用名称。平台尚未建设独立密钥保险库；需要接入 Vault、KMS 等企业密钥系统时，可保持现有 `/api/secrets` 前端契约并替换后端来源。
- 当前门禁指标限定为平台评估器能执行的六类固定指标。自定义表达式规则需要单独的安全表达式引擎，不能只做前端新增输入框。
