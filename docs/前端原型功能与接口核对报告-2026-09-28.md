## 本次补充的后端支持

| 功能点 | 接口或模型 | 落地行为 |
|---|---|---|
| 工作台真实待办 | `GET /api/dashboard/todos` | 按项目、待评审用例、未发布环境和失败运行实时聚合 |
| 工作台项目摘要 | `GET /api/dashboard/projects-summary` | 返回用例数、环境就绪、最近运行和质量评分 |
| 项目列表企业字段 | 扩展 `GET /api/projects` | 服务端搜索/筛选/分页，并返回负责人、用例数、环境与最近运行 |
| 用例表格导入 | `preview`、`commit`、`template` | XLSX/CSV/JSON 预检、事务提交和中文模板下载 |
| 用例评审归档恢复 | `POST /api/cases/:id/restore` | 已归档用例恢复为草稿，重新进入评审链 |
| 最近真实响应 | `GET /api/endpoints/:id/last-response` | 为结构化断言提供状态码、正文、耗时与采集时间 |
| 场景真实试运行 | `POST /api/scenarios/:id/run` | 服务端校验场景与已发布环境归属，真实调用被测服务并返回逐步结果 |
| 场景断言落库 | 场景采纳逻辑 | 采纳用例时保留状态码或 JSONPath 断言，不再强制改成 200 |
| 可视化调度预览 | `POST /api/scheduled-tasks/preview` | 将表单规则转为 Cron 并按 Asia/Shanghai 返回未来触发时间 |
| 调度绑定校验 | 创建/更新定时任务 | 服务端校验目标和环境归属，只接受已发布环境，并固化环境修订快照 |
| 质量门禁规则 | `/api/quality-gate/rules`、`preview` | 运算符、启停、计划范围和最近报告当前值均参与真实评估 |
| 脚本资产 | `GET /api/scripts`、`POST /:id/validate` | 生成记录可分页查看；Python 做语法校验，SQL 做白名单校验 |
| 运行执行摘要 | `GET /api/test-runs/:id/exec-summary` | 返回执行上下文、中位耗时、总耗时和失败用例期望/实际差异 |
| 通知偏好 | `user_preferences`、`GET/PUT /api/notifications/preferences` | 持久化站内/邮件/Webhook/钉钉渠道及免打扰配置 |
| 个人 API Token | `personal_access_tokens`、`/api/auth/me/tokens` | 仅保存 SHA-256 摘要，支持过期、吊销和最后使用时间；明文只返回一次 |

## 明确存在的后端边界

以下能力在原型中出现，但当前没有达到可安全上线的完整后端实现，因此界面没有伪装为已完成：

1. **脚本在线执行**：当前 `POST /api/scripts/:id/validate` 是 Python 语法或 SQL 白名单静态校验，不执行任意代码。企业上线前需要独立 Runner 服务、只读镜像、CPU/内存/时间/网络/文件系统限制和完整审计；不能在主 API 容器中直接 `exec` AI 生成代码。
2. **场景图的任意分支、等待和自定义脚本节点**：当前真实执行链支持串行接口调用、变量提取/注入、条件校验和结构化断言。任意图分支、循环、等待和脚本节点需要版本化 DAG 模型及隔离执行器，现有 JSON 步骤模型不足以安全承载。
3. **独立企业密钥保险库**：`GET /api/secrets` 只聚合环境、仓库和数据库配置中的脱敏凭据引用。完整的密钥 CRUD、版本轮换和细粒度授权仍需 Vault/KMS。
4. **响应头断言取样**：最近响应接口的状态码、正文、耗时和时间来自真实结果，但 `test_results` 尚未持久化响应头，因此样例 `headers` 为空。需要新增结果字段和执行器采集后才能提供真实响应头断言。

这些边界不影响本轮主链路：项目创建 → 文档/需求解析 → 用例生成与评审 → 计划/场景执行 → 报告与门禁 → 通知和审计。脚本执行器、完整 DAG 和密钥保险库应作为独立的安全工程批次实施。
