# 接口用例异步生成与手工执行闭环交付说明

## 修复的问题

接口文档生成原先在一个 HTTP 请求内等待全部模型调用。接口较多、模型超时或账户返回 `402 Insufficient Balance` 时，页面会长时间等待并最终报错；每个接口还会重复触发同类失败。

现改为持久化异步任务：页面先预览生成范围，再提交 Celery 任务。首次模型路由失败后，本批任务立即熔断后续 AI 调用并使用规则模板，每个接口仍生成 15 条基础草稿用例。用户可以离开页面，任务完成或失败后会收到站内通知。

## 数据结构

- `case_generation_tasks`：生成范围、预计/实际用例数、进度、引擎、降级与失败原因、Celery 任务 ID。
- `manual_case_executions`：绑定用例资产及不可变版本，记录执行人、逐步骤结果、实际结果、结论和关联缺陷。
- Alembic 版本：`024_case_generation_manual_execution.py`。

## 新增接口

- `POST /api/cases/generation/preview`：校验接口范围并返回预计产量、已有用例和风险提示。
- `POST /api/cases/generation-tasks`：创建异步生成任务，返回 `202`。
- `GET /api/cases/generation-tasks`：查询项目生成任务。
- `GET /api/cases/generation-tasks/{generation_task_id}`：查询任务详情。
- `POST /api/cases/{case_id}/manual-executions`：开始或恢复本人未完成的手工执行。
- `GET /api/cases/{case_id}/manual-executions`：查询执行历史。
- `PUT /api/cases/{case_id}/manual-executions/{manual_execution_id}`：提交逐步骤结果和最终结论。

## 用户路径

1. 在“智能用例生成 / 接口文档生成”解析并导入接口。
2. 点击“预览并生成”，检查接口数量、预计用例数和已有用例提醒。
3. 提交异步任务，在当前页面查看进度；完成后从站内通知进入任务详情或用例库。
4. 生成的用例仍以草稿落库，进入正式评审任务后才能被测试计划使用。
5. 已评审通过的手工用例在用例列表或详情点击“执行”，逐步登记结果并提交结论；每次执行绑定当时的用例版本，历史记录不可覆盖。

## 部署要求

拉取代码后执行数据库迁移并重启后端和 Celery Worker，使 Worker 加载新增任务模块：

```bash
docker compose exec backend alembic upgrade head
docker compose restart backend celery-worker
```
